# Unreleased

Changes that should be included in the next release go here. Keep this file current during normal development; move the relevant notes into `docs/releases/<version>.md` only when preparing a release.

- Copilot AI-credit limits now refresh automatically: once the sidecar has been created by the explicit Config-page sync, the 15-minute background refresher (and every manual reload) re-fetches it. Deleting `limits/copilot.json` opts back out. All quota-sync HTTP requests (Copilot, Claude, Codex) now carry a 20-second timeout so a stalled connection can no longer wedge the background refresher.
- The Copilot sync's `gh auth token` fallback now works in the desktop app when launched from Finder/Dock: executables are resolved through well-known install directories (`/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`) in addition to `PATH`, with a bounded 10-second wait. The same resolution applies to the local advice CLIs (`codex`, `claude`, `gemini`).
- Stale limit gauges are now labeled and eventually hidden: a row whose reset time has passed (or whose snapshot is over a week old, for windows without a reset) dims with an "as of <date> · stale" note in both the TUI and desktop Usage consoles, and drops out entirely a week later. Reports and exports keep the full snapshot history.
- Copilot Business seats whose payload contains only zero-entitlement placeholder quotas now render an "AI Credits · managed by your organization" row with the plan name instead of an empty section, and org-seat SKUs (`copilot_enterprise_seat_quota`, `copilot_business_seat`, and friends) normalize to Copilot Enterprise / Copilot Business plan labels. A verified real enterprise-seat payload is pinned by a regression test.
- Copilot CLI usage is now exact where the CLI records it: the newer `assistant_usage_events` table (real per-request models, token counts, and cache read/write buckets) supersedes the chars/4 turn estimates and the data.db aggregates for covered sessions, including a one-off archive migration that zeroes previously imported estimates so upgraded archives don't double count.
- Copilot quota sync is now multi-account: it discovers every signed-in GitHub identity (github-copilot credential files, all gh CLI hosts, the Copilot CLI's own account store, and token environment variables), routes GitHub Enterprise Cloud data-residency hosts (`*.ghe.com`) to their regional API endpoints, and writes one sidecar per account so a personal and a work seat render side-by-side gauges labeled with the account login. Single-account setups keep the existing `copilot.json` unchanged, and the token-not-found error now explains where the sync looked.
